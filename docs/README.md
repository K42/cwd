## 🎯 Wybierz Swoją Ścieżkę

### Jestem Użytkownikiem
> *"Chcę stworzyć postać do gry"*

👉 Przejdź do **[HELP.md](HELP.md)**

---

### Jestem Deweloperem
> *"Chcę zrozumieć jak działa kod"*

1. Przeczytaj **[ARCHITECTURE.md](../ARCHITECTURE.md)** - Zrozum ogólną koncepcję
2. Przeczytaj **[APLIKACJA.md](APLIKACJA.md)** - Poznaj szczegóły implementacji
3. Zobacz kod w `src/` - Zacznij od `server.js`

---

### Jestem Mistrzem Gry
> *"Chcę szybko tworzyć NPC"*

1. Przejdź do **[HELP.md](HELP.md#-wskazówki-dla-mistrza-gry)**
2. Użyj Poziomu 0 dla prostych NPC
3. Eksportuj do JSON i zapisz w folderze sesji

---

### Chcę Pomóc w Rozwoju
> *"Chcę dodać nową funkcję"*

1. Przeczytaj **[APLIKACJA.md](APLIKACJA.md)** - Sekcja "Kontrybucja"
2. Sprawdź roadmap w **[README.md](../README.md)**
3. Utwórz Issue lub Pull Request

---

## 📞 Kontakt i Wsparcie

### Znalazłeś błąd?
1. Sprawdź sekcję [Rozwiązywanie Problemów](HELP.md#-rozwiązywanie-problemów)
2. Jeśli problem pozostaje, zgłoś Issue na GitHubie

### Masz pytanie?
1. Sprawdź [FAQ](HELP.md#-często-zadawane-pytania-faq)
2. Przeczytaj odpowiednią dokumentację
3. Zadaj pytanie w Issues/Discussions

### Masz pomysł na ulepszenie?
1. Sprawdź [Roadmap](../README.md#-funkcjonalności)
2. Utwórz Feature Request w Issues
3. (Opcjonalnie) Wyślij Pull Request
